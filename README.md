AI-based palm oil ripeness detection mobile application using CNN, Flutter, and TensorFlow Lite.

## 📱 About The Project

SawitGenZ is a mobile application developed to help determine the harvest eligibility of palm oil fruit using Artificial Intelligence technology.  
This application implements a Convolutional Neural Network (CNN) model for image classification and runs directly on mobile devices using TensorFlow Lite.

This project was developed as a final thesis project focused on improving efficiency and accuracy in palm oil harvest evaluation.

---

## ✨ Features

- 📷 Palm oil fruit image classification
- 🤖 AI-based ripeness detection using CNN
- 📱 Mobile application built with Flutter
- ⚡ Fast on-device inference using TensorFlow Lite
- 🧠 Harvest feasibility analysis
- 🎯 User-friendly interface

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/andrianbagas2004-code/sawitgenz.git
```

### Open Project

```bash
cd sawitgenz
```

### Install Dependencies

```bash
flutter pub get
```

### Run Application

```bash
flutter run
```

## 🧠 AI Model

The CNN model was trained to classify palm oil fruit ripeness categories using image datasets and additional manual parameters.  
The trained model was converted into TensorFlow Lite format for mobile deployment.
